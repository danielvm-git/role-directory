# Specs

This directory contains Agentic-CPS specifications for this project.

## Quick Start

```bash
# Create a new spec
agentic-cps create my-feature

# List all specs
agentic-cps list

# View the board
agentic-cps board

# Validate specs
agentic-cps validate
```

## Structure

Each spec lives in a numbered directory with a `README.md` file:

```
├── 001-feature-name/
│   └── README.md
└── 002-another-feature/
    └── README.md
```

## Spec Status Values

- `draft` - Being authored or refined
- `planned` - Not yet started
- `in-progress` - Currently being worked on
- `complete` - Finished
- `archived` - No longer relevant
